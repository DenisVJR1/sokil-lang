Все, що потрібно компілятору — і нічого зайвого

Сокіл будує весь свій інструментарій самостійно: від компілятора до редактора коду, без сторонніх бібліотек чи рантаймів.

Своя компіляція

Готовий бінарник не потребує встановленого C-компілятора — Сокіл генерує машинний код самостійно, від початку до кінця.

Власна IDE

SokilIDE постачається разом з мовою: підсвітка синтаксису, вбудований запуск файлів і жодних додаткових розширень.

Автооновлення та PATH

Інсталятор самостійно відновлює запис у PATH та перевіряє нові релізи — без ручного налаштування середовища.

Нуль залежностей

Жодних системних бібліотек чи пакетних менеджерів. Один файл — один самодостатній бінарник.

Швидкість виконання

Компіляція напряму в нативний код дає продуктивність, близьку до рукописного C, без проміжного рантайму.

Простий синтаксис

Мінімалістична граматика без зайвих конструкцій — читається так само легко, як і пишеться.

Список можливостей — не остаточний: ми постійно додаємо нові фічі та покращуємо мову з кожним релізом.

Сокіл поруч із Python та JavaScript

Три різні підходи до виконання коду — компільований бінарник проти двох популярних інтерпретованих мов.

Критерій Сокіл Python JavaScript
Модель виконання Компіляція в нативний код Інтерпретація байткоду (CPython) JIT-компіляція в рушії (V8 тощо)
Залежності при запуску Жодних — один бінарник Потрібен встановлений Python Потрібен Node.js або браузер
Дистрибуція Компактний нативний .exe Залежить від пакетів (pip) Залежить від node_modules
Типізація Статична Динамічна (опційні type hints) Динамічна
Швидкість виконання Близька до C Повільніша через інтерпретацію Швидка завдяки JIT, повільніша за нативний код
Найкраще для Системних утиліт, нативних інструментів Скриптів, аналізу даних, прототипів Веб-інтерфейсів, повносистемних застосунків
